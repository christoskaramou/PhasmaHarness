# Main Bot result handling

Empty final answers remain incomplete even when the provider reports a successful turn. `Agents.deliver` keeps an empty report distinct from the display placeholder, and `sendCoordinator` checks it before accepting direct results. Verified 2026-10-24 by `node --test --test-name-pattern="a completed direct worker without a final answer" tests/coordinator.test.cjs`: a marker-only `[task: done]` answer returns without another model call and leaves `hubCompletion.fulfilled` false.

Direct results intentionally add no duplicate assistant bubble. `renderAgents` in `ui/app.js` therefore includes visible result cards when choosing the sidebar preview; otherwise it retains the earlier queued acknowledgement. Internal comparison receipts and superseded results do not replace the preview. Regression: `Direct result sidebar preview replaces the queued acknowledgement` in `tests/ui-startup-smoke.cjs`.

Main Bot chooses `agent_work.resultHandling` in its existing dispatch call. `direct` returns a simple, self-contained task's saved report without selecting a model, compacting chat, reviewing or rewriting the answer. The report card is the answer; it is not duplicated in an assistant bubble. `review` assesses a complex assignment and writes the user-facing reply in the same call. There is no separate response-generation pass. The mode is saved on the original assignment and retained through corrections; older unmarked assignments default to review.

Configured build/test checks run independently in `src/controller/task-gate.cjs`. Both return paths enforce their recorded outcomes through `verificationGaps`, plus failed-worker and truncation guards. Direct handling means the report is relayed, not independently certified. Complex incomplete work can receive the existing bounded correction; failed host checks are never overridden by an optimistic model. Batch returns count each worker, preserve failures and wait for all dispatched results. Each complex worker gets one combined review/reply; the last such call receives the previous results and writes the combined summary. Simple batches need no return-time model calls. `src/controller/suggestions.cjs` also skips optional reply suggestions on Main Bot's automatic result returns, while retaining suggestions after ordinary user chat.

## Timing and input

`src/controller/coordinator.cjs` uses a 120-second inactivity timeout for combined review/reply, ordinary Hub responses and conversation summarization. Result returns skip chat compaction because the review uses bounded original-request/report data. `src/routing/smart-router.cjs` renews the deadline only on nonempty answer/reasoning output from the active provider session/thread, or a returned response. Unrelated notifications do not keep a stuck call alive. Stop and budgets cancel immediately. Normal routing retains its fixed deadline. Providers that expose no intermediate activity still face the silence limit.

`src/agents.cjs` delivers the plain answer as `agentResult.report` and the durable `deliveryId` of its report card. Completion review receives this answer separately from the original request and host verification, avoiding the duplicated assignment and usage metadata in the chat handoff. Current Main Bot project guidance still applies to its combined reply. Older queued records retain a fallback to the stored handoff text. Full-document JSON/schema validation and the maximum of one format retry are unchanged; a combined reply must contain nonempty user-facing text.

## Cursor boundary

`src/providers/cursor.cjs` uses a private review directory with read/write/shell/network/MCP deny settings. Normal workers keep their own settings. A detected classifier tool attempt closes its connection, confirms process cleanup and rejects that response; it cannot approve completion. This is not a guarantee that Cursor never starts a read before emitting its tool notification. ACP's Ask mode permits read/search tools, and the tested pre-tool hook did not reliably block them, so Harness does not rely on that hook. A review that cannot produce valid evidence fails honestly while preserving the worker's report.
